# TheClinixAI Production Website

## Run locally
```bash
python -m http.server 8084
```
Open `http://localhost:8084`.

## Launch configuration
- Replace the four unpublished founder profiles in `about.html` with verified names, roles, portraits and LinkedIn URLs.
- Configure `/api/contact` and `/api/whitepaper-request` with your email or CRM provider before production lead capture.
- Add final PDF files under `assets/` and connect them to the white-paper request workflow.
- Confirm `blogs.theclinixai.com` before enabling live WordPress cards.
