Front End Developer

Hyderabad / Remote · 2–5 years experience · Product Engineering

About the role

Build fast, accessible and polished web interfaces for TheClinixAI products and digital experiences. You will work closely with product, design, backend and QA teams to turn requirements and designs into reliable production interfaces.

Key responsibilities

  • Develop responsive web applications and reusable UI components using modern JavaScript/TypeScript and React or an equivalent framework.
  • Translate Figma or design specifications into accurate, accessible and responsive interfaces.
  • Integrate REST/GraphQL APIs and handle loading, error, empty and validation states.
  • Build reusable component patterns and maintain front-end code quality and consistency.
  • Optimize page performance, accessibility, Core Web Vitals and cross-browser compatibility.
  • Write unit and component tests and participate in code reviews.
  • Debug production issues and collaborate with QA and backend engineers on root-cause resolution.
  • Use Git, CI/CD and documented development workflows.
  • Contribute to design-system and UX improvements.

Required qualifications

  • Bachelor's degree in Computer Science, IT or related field, or equivalent practical experience.
  • 2–5 years of professional front-end development experience.
  • Strong HTML5, CSS3, JavaScript and responsive-design fundamentals.
  • Hands-on React experience; TypeScript preferred.
  • Experience consuming APIs and working with Git-based development.
  • Strong attention to UI detail and problem-solving ability.

Preferred skills

  • Next.js, Vite, Tailwind or another modern UI stack.
  • Accessibility, performance optimization and analytics instrumentation.
  • Experience with healthcare, life-sciences or enterprise applications.
