INFORMATION TECHNOLOGY · FULL-TIME

Web Developer

Hyderabad / Remote · 1–3 years experience · Digital Platforms

About the role

Build and maintain TheClinixAI's public websites, landing pages, campaign experiences and internal web interfaces. This role suits a practical web developer who cares about performance, responsive design, SEO and clean implementation.

Key responsibilities

  • Develop and maintain responsive websites using HTML, CSS, JavaScript and modern web tooling.
  • Implement landing pages and reusable sections from designs and content requirements.
  • Maintain navigation, forms, analytics tags, SEO metadata, structured data and technical integrations.
  • Optimize performance, image delivery, Core Web Vitals and mobile usability.
  • Test across browsers and devices and resolve layout, accessibility and functional defects.
  • Work with marketing, design, product and engineering teams on website releases.
  • Manage Git-based changes and documented deployment workflows.
  • Support content updates and diagnose production website issues.

Required qualifications

  • 1–3 years of hands-on web development experience.
  • Strong HTML, CSS and JavaScript fundamentals.
  • Experience with responsive design, Git and browser debugging.
  • Understanding of SEO basics, page speed and web analytics.
  • Strong visual attention and ability to implement designs accurately.

Preferred skills

  • React, Next.js, WordPress or another modern web stack.
  • GA4, Google Search Console, Tag Manager and structured data.
  • Basic knowledge of accessibility, security headers and deployment platforms such as Vercel.
