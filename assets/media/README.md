# ClinixAI Media Library

## Naming
Use lowercase kebab-case. Prefix product interface renders with `ui-`, illustrations with `illustration-`, and backgrounds with `bg-`.

## Raster standards
- Product UI hero render: 2560 × 1600 PNG or WebP
- Social landscape: 2400 × 1260 PNG
- White-paper figure: 1920 × 1080 PNG
- No baked-in rounded corners or outer shadows

## Governance
Every media asset must be listed in `media-manifest.json`. Dashboard data is illustrative unless sourced from validated product output.
