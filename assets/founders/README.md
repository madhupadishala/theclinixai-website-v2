## Recommended export

- Canvas: **600 × 750 px** (4:5 portrait)
- Format: **WebP**
- Target file size: **under 120 KB**
- Crop: head and shoulders, with room around the face
- Background: simple neutral or transparent-looking studio background
- Avoid employer logos, badges, office IDs and confidential environments

The website displays each image at approximately **180 × 225 px on desktop**, **145 × 181 px on tablet**, and **118 × 148 px on mobile**. Images are intentionally monochrome and reduced in prominence.

Use portraits only with each person's approval. A stylised or AI-generated editorial portrait is acceptable when the person has consented to that representation. If an image is missing, the person's initials remain visible automatically.
